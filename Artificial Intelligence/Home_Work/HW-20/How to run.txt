====================  Новий варіант запуску  ==========
1.У Терміналі 1, запустіть фабрику знову, 
але з "чарівним" ключем -d (це означає "detached" або "у фоні").
	Bash: docker-compose up -d --build
2.Що станеться: Docker побудує і запустить всі ваші контейнери, 
але не буде показувати їхні логи. 
Ваш термінал просто скаже [+] Running 4/4 і поверне вам командний рядок 
(наприклад, PS D:\...).
3.Все! Ваша "фабрика" тепер працює тихо, як привид.
4.Спілкування" (Використовуємо "Пульт")
Тепер ваш Термінал 1 вільний! Вам не потрібен Термінал 2.
5.Прямо тут, у Терміналі 1, введіть команду "пульта":
	Bash: docker-compose exec controller python main.py
6.Ось! Тепер вас запитають: 
Якого героя Marvel ви б хотіли обговорити? (або 'exit'):
7.Напишіть Iron Man і натисніть Enter

Підсумок (Новий, простий процес):
1.Один раз запускаємо у терміналі: docker-compose up -d
2.Запити робимо у тому ж терміналі: docker-compose exec controller python main.py
3.Результати дивимося ТІЛЬКИ у вікнах Docker Desktop на вкладках Logs.
4.Цей спосіб набагато чистіший і саме так працюють професіонали. Спробуйте!
